# Haiku Salon

日常のふとした瞬間に俳句を詠み、気軽に共有できるサービス。

友人や知人と俳句を通じて交流するための Web サービスです。日々の何気ない発見や感情を俳句にして投稿したり、誰かの俳句に返句したりすることで、言葉を通じたゆるやかな繋がりを楽しめます。

## 1. プロジェクトの目的

俳句をもっと身近に、もっと気軽に楽しめる場所を作ることを目的としています。

他人に見せる俳句でなく、人生を深く味わうための補助サービスとして使用して欲しいという思いから、Haiku Salonではあえて通知機能がないです。

時間や返信のタイミングに縛られず個人のペースで俳句を投稿・鑑賞できます。

また、俳句の世界観や余韻を大切にしながら、いいねや返句を通じて日常の風情を共有できる場所を目指しています。

## 2. デモ

**デモサイト：** [Haiku Salon](https://nanraka.github.io/Haiku-Salon/)

※ ルームへの参加には、共有された Room の URL が必要です。


## 3. 機能・特徴

- **Room 機能**：Room 単位で俳句を共有し、友人や知人と交流できます。
- **俳句の投稿**：思いついた俳句を気軽に投稿できます。
- **いいね機能**：気に入った俳句にリアクションを送れます。
- **返句機能**：投稿された俳句に対して、俳句で応答できます。
- **URL による共有**：Room の URL を共有することで、アカウント登録なしで参加できます。

気軽に投稿できること、俳句ならではの余韻を楽しめることを大切にしています。

## 4. 使用方法

1. [Haiku Salon](https://nanraka.github.io/Haiku-Salon/) にアクセスします。
2. 参加したい Room の URL を開きます。
3. 俳句を投稿したり、ほかの人の俳句にいいねや返句を送ったりして楽しみます。

Room の URL は、参加する友人や知人に共有してください。

## 5. 開発・貢献方法

Haiku Salon は、ユーザーが自由に機能を追加・改善できることを目指したオープンソースプロジェクトです。

「こんな機能があったら面白そう」「ここをもっと使いやすくしたい」といったアイデアがあれば、ぜひ実装してみてください。

### 変更・追加してよいもの

基本的に、ライセンスの条件に従う限り、自由に変更・追加して構いません。

例えば、以下のような変更を歓迎します。

- 新しい機能の追加
- UI・デザインの改善
- スマートフォンや PC での操作性の改善
- バグ修正やパフォーマンス改善
- コードの整理やリファクタリング
- テストやドキュメントの追加
- 新しい遊び方や俳句の楽しみ方の提案


### 開発で大切にしたいこと

機能追加にあたっては、次の点を意識してもらえるとうれしいです。

- **気軽さを大切にする**：俳句を投稿するまでの手間や心理的な負担をできるだけ増やさない。
- **俳句の世界観を大切にする**：交流を促しつつ、俳句の余韻や自由な鑑賞を妨げない。
- **既存機能への影響を確認する**：投稿、いいね、返句、Room への参加など、既存の機能が正常に動作することを確認する。
- **安全性を意識する**：データベースのアクセス制御や、ユーザーが入力した内容の取り扱いに注意する。
- **変更内容を共有する**：大きな仕様変更や既存機能への影響が大きい変更は、実装前に相談する。

これらは開発の方向性を共有するための目安であり、アイデアを制限するための厳格なルールではありません。

### 貢献の流れ

GitHub を利用した開発を歓迎します。

1. リポジトリを確認し、変更したい機能や改善点を決める。
2. 必要に応じて Issue でアイデアや実装方針を共有する。
3. ブランチを作成し、機能追加や修正を行う。
4. 既存機能への影響や動作を確認する。
5. Pull Request で変更内容を共有する。

小さな改善や実験的な機能追加も歓迎します。開発に慣れていない方も、気軽に参加してください。

### 開発時の注意事項

- API キー、パスワード、アクセストークンなどの秘密情報をソースコードに含めないでください。
- Supabase の設定を変更する場合は、データベースの Row Level Security（RLS）やアクセス制御が適切に維持されていることを確認してください。
- 依存ライブラリを追加する場合は、必要性やライセンスを確認してください。
- 実際に利用されているデータを変更・削除する可能性がある場合は、事前に相談してください。

## 6. 技術構成

本プロジェクトでは、GitHub Pages を利用した Web サイトの公開と、Supabase を利用したデータ管理を行っています。

- **GitHub**：ソースコードの管理・共同開発
- **GitHub Pages**：Web サイトの公開
- **Supabase**：俳句などのデータ管理

構成や実装の詳細については、リポジトリ内のソースコードを参照してください。
