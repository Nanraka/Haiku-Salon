# Haiku Salon Prototype

「俳句を、置いておこう。」をコンセプトにした、Haiku Salon のスマートフォン向け静的プロトタイプです。

## 現在できること

- 部屋を作る
- 部屋名・参加者名を設定する
- 部屋URLを生成する（デモではハッシュURL）
- 俳句を投稿する
- 俳句に「いいね」する
- 俳句の詳細を見る
- 俳句に返句する
- 参加者一覧を見る
- データをブラウザの localStorage に保存する

## 重要

これは UI / 操作感を確認するためのプロトタイプです。

`localStorage` を使っているため、別の人のブラウザとデータを共有することはできません。

実サービス化するときは、

- GitHub Pages：HTML / CSS / JavaScript の公開
- Backend / Database：部屋・俳句・いいね等の共有データ保存

という構成に変更します。

## GitHub Pages

このフォルダの中身をGitHubリポジトリのルートに置けば、静的サイトとして公開できます。

`index.html` が入口です。

## デザイン方針

- 淡い生成り色
- くすみグリーン
- 少量の淡いアクセントカラー
- 大きめの角丸
- 余白を多くする
- 俳句を主役にする
- LINE / SNS らしさを避ける
- 古風な和風サイトになりすぎない
